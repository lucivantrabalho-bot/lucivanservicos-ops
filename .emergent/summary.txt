<product_requirements>
The user requested a Pendency Management Application (Aplicativo de gerenciamento de pendências) with the following specifications:

**Core Structure:**
*   User registration with authentication (login/password).
*   Each user can open and view pendencies.
*   All pendencies stored in a dashboard, filterable by site and exportable to Excel.

**Pendency Creation Fields (Mandatory):**
*   **SITE** (text)
*   **Data e Horário** (auto-generated upon opening)
*   **Tipo da Pendência:**
    *   **Energia:** Controladora, QDCA, QM, Retificador, Disjuntor, Bateria, Iluminação Pátio, Sensor de Porta, Sensor de Incêndio, Iluminação Gabinete/Container, Cabo de Alimentação.
    *   **Arcon:** Trocador de Calor, Sanrio, Walmont, Limpeza, Contatora, Compressor, Gás, Fusível, Placa Queimada, Transformador, Relé Térmico, Relé Falta de Fase, Comando, Alarme.
*   **Observações** (free text)
*   **Foto** (attach from gallery or take on the spot)

**Functionalities:**
*   Pendency automatically sent to dashboard upon creation.
*   Pendency status initially Pendente until finalized by a user.
*   Any user can view all open pendencies, separated by site on the dashboard.
*   Dashboard to export data in Excel format.

**Technical Requirements:**
*   Backend: FastAPI (Python).
*   Frontend: React (Web).
*   Database: MongoDB.
*   Excel Export: Appropriate library (e.g.,  for Python).
*   Image Upload: Stored locally (using base64 in this implementation).

**Extras / Enhancements (implemented iteratively):**
*   Simple and intuitive interface.
*   Dashboard filters: by site, pendency type, and status (pending/finalized).
*   Pendency history: who opened/finalized, date/time (implicitly handled by audit fields).
*   **Mandatory photos** for creation and finalization.
*   **Finalization details**: field for closing information upon finalization.
*   **Edit/Delete pendencies** when status is Pendente.
*   **Branding updates**: change Dashboard to Gerenciador CN19, PendênciaHub to Gerenciador CN19, Sistema de Gerenciamento de Pendências to Sistema de Gerenciamento de informações do CN19.
*   **Brasília timezone** for all dates/times.
*   **Admin roles**:
    *   Login approval for new users by Admin.
    *   Password reset only by Admin.
    *   Only Admin can export Excel.
    *   Admin profile with validation field for pendencies (button to return to Pendente if not according).
    *   Admin can edit form fields for Nova Pendência.
*   **User Profile**: Option to change password, show monthly statistics.
*   **Dashboard Highlights**: User who opened most pendencies and user who finalized most pendencies (monthly, with history).
*   **Icons**: Replace current icons with a telecommunications tower.
</product_requirements>
